# dsh-sidebar-status

DeepSeek 账号余额 + 当前计费时段，固定在侧边栏底部。

```
  余额 ¥10.46  ⟳  ● 空闲时段            去充值
```

- **余额** —— 充值余额 + 赠金余额（有赠金时才显示），需要登录 DeepSeek 账号
- **⟳** —— 手动刷新
- **时段** —— 高峰时段 / 空闲时段，鼠标悬停看下一段什么时候开始
- **去充值** —— 打开官方充值页

## 安装

设置 → 插件 → 添加插件，贴进去：

```
dsh-sidebar-status
```

国内可直连（npm 镜像会自动同步）。如果提示找不到，改用这个 GitHub 地址：

```
github:sunzphy/dsh-sidebar-status
```

装完刷新页面即可。卸载也在同一个界面。
